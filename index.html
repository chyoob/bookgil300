키를 넣으면 말하는 즉시 글로 나옵니다. 키가 없으면 브라우저 내장 인식을 씁니다.

2. 정리 · Anthropic Claude

키는 기본으로 이 기기에만 저장됩니다. 위 상자를 켜면 파일 안에 키가 들어갑니다. 파일을 남에게 주면 키가 그대로 보입니다. 혼자 쓸 때만 켜세요.

마이크를 켜려면

  1. 파일을 그냥 열면(file://) 크롬이 마이크를 막습니다.
  2. GitHub에 저장소를 만들고 이 파일을 index.html로 올립니다.
  3. Settings → Pages → Branch: main → Save. 잠시 뒤 https://아이디.github.io/저장소/ 주소가 생깁니다.
  4. 갤럭시 크롬에서 그 주소를 엽니다. 마이크 버튼을 누르고 "허용"을 누릅니다.
  5. 크롬 메뉴 → "홈 화면에 추가"를 누릅니다. 앱 아이콘이 생깁니다.

웹에 올린 파일에는 기록이 없습니다. 기록은 저장 버튼으로 내려받은 파일 안에만 남습니다.
